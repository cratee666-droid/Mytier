For the best experience and to access all content on this site, please use Cloudflare's 1.1.1.1 DNS before continuing.
🌐 Recommended DNS: 1.1.1.1 & 1.0.0.1
📱 How to Switch DNS on Mobile Browser
1
Easiest — Download App: Install the free 1.1.1.1 app by Cloudflare from App Store or Google Play, then tap the toggle to enable it.
2
Chrome Mobile: Tap ⋮ Menu → Settings → Privacy and Security → Use Secure DNS → Choose Custom → enter https://1.1.1.1/dns-query
3
Firefox Mobile: Tap ☰ Menu → Settings → DNS over HTTPS → Custom → enter https://1.1.1.1/dns-query
4
Wi-Fi DNS (Android): Settings → Wi-Fi → Long press network → Modify → Advanced → IP Settings: Static → DNS 1: 1.1.1.1 DNS 2: 1.0.0.1
5
Wi-Fi DNS (iPhone): Settings → Wi-Fi → tap ℹ️ next to network → Configure DNS → Manual → add 1.1.1.1 and 1.0.0.1
⚡ 1.1.1.1 is faster, more private and bypasses regional restrictions. Cloudflare never sells your data.
